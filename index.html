Abstract

Code-as-Policies enables vision-language models (VLMs) to perform robotic manipulation by generating code that coordinates perception and control. However, existing coding agents typically rely on visual and proprioceptive signals, while lacking mechanisms to manage and reuse tactile information for contact-rich manipulation. We introduce TouchMem, a robotic manipulation framework built on CaP-X that enables VLM-based coding agents to acquire, remember, and reuse tactile manipulation skills. Corresponding to these three operations, TouchMem integrates three components: tactile representation, memory compression, and memory retrieval. Specifically, the representation module acquires contact information by encoding raw sensor readings into compact physical features for code generation. Memory compression remembers interaction histories under a limited context budget as concise contact records and reusable skills, while memory retrieval reuses relevant records and skills verified against online sensor feedback for closed-loop control. To validate TouchMem, we build TouchMem-Bench, an eight-task simulation benchmark, and compare different representations and memory mechanisms across this benchmark and two real-world robot tasks. Experiments show that TouchMem reaches 86.3% and 77.5% average success in representation and memory evaluations on TouchMem-Bench, while also outperforming baselines on real-world tasks.
